Дуализм картасы

Әр күй осы жазықтықта бір нүкте. Шуылсыз нүкте шекті сызықта жатады.

Шуыл күшейгенде

Детектор мен N бұрынғыша қалады, тек шуыл 0%-дан 100%-ға дейін өседі.

C (l₁) C (салыстырмалы энтропия) D (шуылға тәуелсіз)

Формулалар

  • |Ψ⟩ = (1/√N) Σj |j⟩|dj⟩,  γ = |⟨di|dj⟩| = cos(πκ/2)
  • Шуыл (дефазация): ρ → (1 − λ)ρ + λ·diag(ρ),  ρij = c/N (i ≠ j), ρjj = 1/N,  c = (1 − λ)γ
  • Cl₁ = (1/(N−1)) Σi≠j |ρij| = c
  • Crel = 1 − S(ρ)/ln N,  ρ-дың меншікті мәндері: (1 + (N−1)c)/N (бір рет) және (1 − c)/N (N−1 рет)
  • D = 1 − (1/(N−1)) Σi≠j √(pipj)·|⟨di|dj⟩| = 1 − γ
  • Cl₁ + D = 1 − λγ ≤ 1
  • I(θ) = (1 − c) + c·sin²(Nθ/2) / (N·sin²(θ/2))

Барлық жолдың ықтималдығы тең (1/N), детектордың күйлері симметриялы (қабаттасуы бірдей). Дефазация қоршаған ортаның жолды ішінара өлшеуімен пара-пар, сондықтан C + D шектен төмен түскенде, айырма қоршаған ортаға кетті деп оқуға болады. Қарастырылған модельде Crel ≤ Cl₁, екеуі де 0 және 1 мәндерінде сәйкес келеді. Дуализм қатынасы: Bera және т.б. (2015); когеренттілік өлшемдері: Baumgratz және т.б. (2014).
